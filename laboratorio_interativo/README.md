# Laboratório Interativo — Modelagem Matemática e IA

Aplicativo interativo associado ao livro **Modelagem Matemática e Inteligência Artificial: problemas revisitados, novas perguntas**, de **Rodney Carlos Bassanezi** e **João de Deus Mendes da Silva**.

## Versão

- Aplicativo: **1.0.0**
- Data de registro no repositório: **2026-10-14**
- Integração ao repositório computacional: **v1.1.0**

## Objetivo

O laboratório articula visualmente o percurso do livro, partindo do problema das maçãs e avançando para problemas de empacotamento de esferas e recipientes.

A interface foi concebida para exploração didática e investigação, preservando a distinção entre:
- simulação;
- construção geométrica;
- busca heurística;
- resultado matematicamente provado.

## Execução

O aplicativo é autocontido. Não requer instalação, Python ou acesso à internet.

Abra diretamente:

`index.html`

em Chrome, Edge ou Firefox.

## Módulos

1. **Maçãs & FCC** — propagação estocástica em rede FCC e comparação de posições iniciais.
2. **Da maçã à esfera** — idealização geométrica e empacotamento no cubo.
3. **Mudar o recipiente** — problema inverso e comparação de recipientes.
4. **De volta às maçãs** — dimensionamento de um recipiente cúbico para um número dado de maçãs.

## Reprodutibilidade

No módulo estocástico, resultados individuais dependem das sementes e dos parâmetros escolhidos. Uma realização computacional não deve ser confundida com uma média de muitas simulações.

Nos módulos de otimização, uma configuração obtida heuristicamente constitui evidência computacional ou construção, não prova de otimalidade.
